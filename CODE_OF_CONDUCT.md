# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good faith, critique code and methodology rather than people, and keep
discussions about competing libraries factual. Harassment, personal attacks and discriminatory language are not
tolerated in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour privately to the repository maintainers through GitHub (for example a private security
advisory or a direct message to a maintainer listed on the repository). Reports are handled confidentially, and
maintainers may remove content or block participants who violate this code, following the Contributor Covenant's
enforcement guidelines.
