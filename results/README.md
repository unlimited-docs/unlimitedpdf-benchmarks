# Run folders

`scripts/run-benchmarks.ps1` and `scripts/run-benchmarks.sh` write one folder per run here (`results/<run-id>/`). Run
folders are ignored by git; keep them, with their manifest, when sharing results.

| Path | Contents |
|---|---|
| `manifest.json` | Run id, UTC start, profile and arguments, git commit and dirty flag, environment, component versions, fixture version and SHA-256, font checksums |
| `validation.json` | Status, reason, failures, output size, pages and validators for every case (including unsupported ones) |
| `samples/` | The first output of each scenario and library, and a PDFium render of page 1 |
| `bdn/` | Raw BenchmarkDotNet log and Markdown, CSV, HTML and full JSON exports |
| `profiler/results.json` | Resource-profiler results including resource time series |
| `report.html`, `summary.md`, `results.csv`, `results.json` | Generated by `UnlimitedPDF.Benchmarks.Reporting`; regenerate with `scripts/generate-reports.ps1` |

Documented runs are summarized in [docs/results](../docs/results/).
